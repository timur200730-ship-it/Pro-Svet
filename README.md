# 🌅 Просвет — спокойный путь к нулю долгов

**Просвет** — это личное, приватное и красивое веб-приложение для управления долгами и финансового планирования. Всё считается и хранится только на вашем устройстве. Никаких серверов, аккаунтов и слежки.

## ✨ Возможности

- **Учёт долгов**: карты, кредиты, рассрочки, ипотека.
- **Стратегии погашения**: «Лавина» (математически выгодно), «Снежный ком» (психологически комфортно) и «Свой порядок».
- **Умные рекомендации**: приложение подскажет, с какого долга начать, предупредит об отрицательной амортизации и покажет, как дополнительные платежи влияют на срок.
- **Детализация платежей**: амортизация по каждому долгу с разбивкой на проценты и тело.
- **Сравнение стратегий**: наглядный график «Лавина vs Снежный ком».
- **Кредитные калькуляторы**: ипотека, автокредит, досрочное погашение.
- **Аналитика MOEX**: анализ 50 ликвидных российских акций и ОФЗ с рекомендациями (данные с задержкой ~15 минут).
- **PWA**: устанавливается на телефон и работает офлайн.
- **Экспорт/Импорт**: резервная копия всех данных в JSON.

## 🚀 Как запустить

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в браузере (лучше через локальный сервер, например `python -m http.server`).
3. Готово! Все данные сохраняются в `localStorage` вашего браузера.

## 🛠️ Технологии

- Чистый **HTML5, CSS3, JavaScript (ES6+)**. Без фреймворков и сборщиков.
- **Canvas API** для графиков.
- **MOEX ISS API** для рыночных данных.
- **Service Worker** для офлайн-режима.

Этот проект создан в образовательных и личных целях. Он не является финансовой рекомендацией. Данные по рынку предоставляются «как есть» и могут содержать задержки. Всегда проверяйте информацию у профессиональных консультантов.
